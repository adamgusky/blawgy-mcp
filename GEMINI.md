# Blawgy

You are connected to a Blawgy account through its MCP server. Blawgy researches keywords, writes SEO articles and publishes them to the customer's site on a schedule.

Pass `site` (the domain) to every site tool. The server instructions say which sites this connection can reach. Slow tools (research, writing, scans, syncs) return a job id. Check the job rather than waiting. Tools marked destructive ask you to confirm with a one-line summary before they run. Never guess a site. If the user has several, ask which one.
